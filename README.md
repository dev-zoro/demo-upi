Demo UPI 
The UPI website is entirely built using raw web development technologies, including HTML, CSS, and vanilla JavaScript.
For storage, the browser's local storage and session storage are used.

Register on the website (be careful, don't enter your sensitive data) and then log in.
You will get options to transfer money using:
1. Mobile Number
2. Bank Account
3. Self Transfer

Click on the top right corner button, which has your name. You will enter the profile section. 
Profile section has options:
1. Information
2. Bank Account
3. Transactions
4. logout

The navbar has options:
1. Home
2. About
3. Contact
4. Use Button

It's a practice project to enhance my front-end skills.

The feature/develop1.0 branch has the latest code, which I am working on.
The release1.0 branch is deployed using GitHub Pages.
